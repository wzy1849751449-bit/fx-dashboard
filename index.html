汇率走势与议价点

CRDB 中间价 − BOT 中间价

银行牌价相对央行的偏离。负值越大＝CRDB 中间价比央行低越多，这种时候柜台往上让价的空间通常更小。

CRDB 中间价 − XE 国际中间价

银行牌价相对国际市场的偏离，用来判断本地报价是领先还是滞后于外盘。

每笔议价相对基准的价差

正数＝议价高于该基准。你在买入美元时数字越低越好，卖出美元时越高越好。

换汇时机复盘

每笔议价当天的 BOT 中间价，在此前 30 天区间里处在什么位置。

汇率明细

每个工作日东非时间上午 11 点自动抓取并追加。空白＝当天该数据源没有发布（周末、公众假期属正常）。

写入令牌

没有令牌也能看全部内容，但改不了数据。令牌只保存在你这台设备的浏览器里， 不会上传到仓库，也不会被其他访问者看到。公用电脑上请用完点「清除」。

怎么生成令牌
  1. 打开 GitHub → Fine-grained personal access token
  2. Token name 随便填，比如 fx-dashboard；Expiration 建议选 1 年
  3. Repository access 选 Only select repositories，勾上 fx-dashboard
  4. Permissions → Repository permissions → 找到 Contents，改成 Read and write
  5. 生成后复制 github_pat_… 粘贴到上面，点保存

访问口令

换口令会用新口令重新加密议价数据并上传。换完要通知所有需要访问的人， 旧口令在发布完成后（约 1 分钟）失效。忘记口令没有找回途径——数据是真加密的。

关于这个看板

数据来源
口径说明
· CRDB 中间价 =（买入价 + 卖出价）÷ 2
· 买入美元时对照 CRDB 卖出价，省下的钱 =（卖出价 − 议价）× 美元金额
· 卖出美元时对照 CRDB 买入价，多拿的钱 =（议价 − 买入价）× 美元金额
· BOT / XE 缺失的日子在计算中向前取最近一个有效值

安全边界
网站本身托管在 GitHub Pages（公开）。行情数据是各家银行的公开牌价，明文存放； 议价汇率、换汇金额、备注这些敏感内容是 AES-256-GCM 密文，没有口令拿到源文件也解不开。 口令是共享的——要收回某个人的访问权限，到「访问口令」里换一个新的。
数据仅供内部分析参考，银行实际成交以柜台为准，不构成任何交易建议。
